# Usman Prayer Timings - Faisalabad, Pakistan
**Perpetual Hanfi Saum-o-Salat Timetable** (Islamic Academy, 31° 25' N, 73° 4' E).

## Mobile Installation Guide

### Option 1: 1-Tap Mobile Install (Instant PWA - No APK Needed)
1. Open `index.html` on your mobile phone in Google Chrome, Samsung Internet, or Microsoft Edge.
2. Tap the browser menu (**⋮** three dots in top right).
3. Select **"Install app"** or **"Add to Home screen"**.
4. The app with the green and gold Mosque icon named **"Usman Prayer Timings"** will be installed on your mobile home screen and app drawer!
5. It launches full screen without any browser navigation bar and works 100% offline.

### Option 2: Building a Standalone Android APK (.apk)
If you require an `.apk` installer file for distribution or sideloading:
1. Upload the files in this folder to any web host (GitHub Pages, Netlify, Vercel, or your own server) for free.
2. Visit **[PWABuilder.com](https://www.pwabuilder.com)** (Microsoft's official open-source tool for converting PWAs to Android APKs).
3. Enter your web app URL.
4. Click **"Package for Android"** -> select **"Download APK"**.
5. PWABuilder builds and signs a production-ready `.apk` package that you can install directly on any Android smartphone!
